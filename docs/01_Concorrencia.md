# Análise de concorrência

## 1. Principais concorrentes

### Reddit

**Link:** [Reddit](https://www.reddit.com/?utm_source=chatgpt.com)

**Descrição:**
O Reddit é uma rede social baseada em comunidades, chamadas *subreddits*, nas quais os usuários podem criar publicações, comentar e votar em conteúdos. Para o público interessado em jogos, existem diversas comunidades dedicadas a jogos específicos, gêneros, plataformas e discussões sobre a indústria.

Ele é um concorrente **indireto**, pois não é exclusivamente uma plataforma de avaliação de jogos, mas oferece recursos muito próximos do objetivo do projeto, principalmente **comentários, avaliações/opiniões, discussões e interação entre usuários**.

---

### Letterboxd

**Link:** [Letterboxd](https://letterboxd.com/?utm_source=chatgpt.com)

**Descrição:**
O Letterboxd é uma rede social voltada para filmes. Os usuários podem registrar filmes assistidos, dar notas, escrever avaliações, criar listas e acompanhar as atividades de outras pessoas.

Apesar de ser focado em cinema, ele é um **concorrente representativo importante**, pois apresenta um modelo muito próximo ao que a nossa plataforma pretende aplicar aos jogos: **catálogo de itens + avaliação + comentários + perfil do usuário + listas + interação social**.

---

# 2. Características e funcionalidades

### Reddit — principais características

* Comunidades específicas (*subreddits*);
* Publicações de texto, imagens e vídeos;
* Sistema de **upvote/downvote**;
* Comentários e respostas;
* Sistema de karma;
* Busca por conteúdos;
* Perfil do usuário;
* Seguir comunidades e usuários;
* Moderação feita por usuários e moderadores.

### Letterboxd — principais características

* Catálogo de filmes;
* Avaliação por estrelas;
* Reviews escritas;
* Curtidas em reviews;
* Comentários;
* Perfil do usuário;
* Diário de filmes assistidos;
* Listas personalizadas;
* Histórico de avaliações;
* Seguir outros usuários;
* Descoberta de filmes.

---

# 3. Opiniões sobre a experiência do usuário (UX)

### Reddit

**Pontos positivos frequentemente associados à UX:**

* Grande quantidade de comunidades;
* Facilidade para encontrar pessoas interessadas nos mesmos assuntos;
* Sistema de votação ajuda a destacar conteúdos considerados relevantes;
* Discussões bastante completas;
* Grande quantidade de conteúdo produzido pelos próprios usuários.

**Pontos negativos:**

* Grande quantidade de informações pode causar sensação de confusão;
* Interface pode parecer complexa para novos usuários;
* Discussões muito longas podem dificultar encontrar informações;
* Qualidade das respostas varia bastante;
* Dependência de comunidades e moderadores.

### Letterboxd

**Pontos positivos:**

* Interface bastante focada em filmes;
* Facilidade para registrar e avaliar filmes;
* Sistema de listas facilita organização;
* Perfis permitem visualizar o gosto de outros usuários;
* Reviews ficam associadas diretamente aos filmes;
* Boa experiência para descoberta de novos filmes.

**Pontos negativos:**

* Algumas funcionalidades são limitadas na versão gratuita;
* Grande quantidade de informações pode deixar algumas telas carregadas;
* Algumas funcionalidades sociais podem não ser óbvias para usuários novos;
* O sistema é bastante direcionado para quem já possui interesse em acompanhar filmes e avaliações.

O modelo de negócio envolve principalmente:

* publicidade;
* assinaturas;
* recursos pagos;
* monetização do ecossistema da plataforma.

Para o usuário comum, grande parte das funcionalidades principais pode ser utilizada gratuitamente.

### Letterboxd

O Letterboxd utiliza um modelo **freemium**.

Existe uma versão gratuita e planos pagos, atualmente voltados principalmente para usuários que desejam recursos adicionais.

O modelo envolve:

* versão gratuita;
* assinaturas;
* recursos exclusivos para assinantes;
* publicidade na versão gratuita.

**Valor PRO: R$52,90**

**Valor PATRON: R$134,90**

# 5. Padrões e tendências encontrados

### Avaliação feita pelo usuário

Os dois utilizam o usuário como fonte principal de conteúdo, permitindo que as pessoas compartilhem suas opiniões e experiências sobre os conteúdos disponíveis.

**Tendência:** plataformas estão cada vez mais utilizando conteúdo gerado pelos próprios usuários para criar informações e opiniões sobre os conteúdos disponíveis.

### Comentários e discussões

A possibilidade de comentar cria uma experiência mais social do que simplesmente dar uma nota. No Reddit, as discussões são uma das principais formas de interação, enquanto no Letterboxd os usuários podem comentar e discutir sobre as avaliações.

**Tendência:** plataformas estão transformando avaliações em discussões e incentivando a interação entre os usuários.

### Perfil do usuário

Os dois apresentam informações relacionadas às atividades do usuário. No Reddit, o perfil reúne as interações e publicações, enquanto no Letterboxd apresenta avaliações, filmes assistidos e listas.

**Tendência:** plataformas estão utilizando perfis personalizados para mostrar os interesses e atividades de cada usuário, criando uma espécie de identidade dentro da plataforma.

### Interação social

Curtidas, votos, seguidores e comentários aparecem como mecanismos de interação nas duas plataformas, incentivando os usuários a participar e interagir com outros membros.

**Tendência:** recursos comuns de redes sociais estão sendo incorporados em plataformas de conteúdo para aumentar o envolvimento dos usuários.

### Listas e organização

O Letterboxd demonstra como listas podem ser utilizadas para organizar conteúdos de acordo com os interesses de cada usuário.

No projeto de vocês isso poderia virar, por exemplo:

* "Meus jogos favoritos"
* "Jogos que quero jogar"
* "Melhores jogos de 2026"
* "Jogos para jogar com amigos"

**Tendência:** plataformas estão permitindo que os usuários organizem e personalizem os conteúdos de acordo com seus próprios interesses.

### Descoberta de conteúdo

Outro padrão importante é permitir que o usuário descubra novos conteúdos por meio de:

* busca;
* categorias;
* avaliações;
* recomendações;
* atividades de outros usuários.

**Tendência:** plataformas estão facilitando a descoberta de novos conteúdos utilizando informações como interesses, avaliações e atividades da comunidade.

# 6. Relatório e resumo dos resultados

**Análise geral**

A análise dos concorrentes Reddit e Letterboxd permitiu identificar diferentes padrões de interação e organização de conteúdo que podem ser aplicados ao projeto. O Reddit se destaca principalmente pela interação entre usuários, discussões e organização por comunidades, enquanto o Letterboxd apresenta uma experiência mais estruturada para avaliação, registro e organização de conteúdos.

Apesar de atuarem em áreas diferentes, ambas as plataformas apresentam funcionalidades relevantes para uma plataforma voltada ao público gamer, como avaliações, comentários, perfis, interação social, listas e mecanismos de descoberta.

Dessa forma, os dois concorrentes apresentam características que podem servir como referência para o desenvolvimento da interface e da experiência do usuário da plataforma proposta.

# 7. Pontos positivos, negativos e recomendações

### Reddit

**Pontos positivos**

* Comunidade muito ativa;
* Grande quantidade de conteúdo;
* Discussões detalhadas;
* Sistema de votação;
* Organização por comunidades.

**Pontos negativos**

* Interface pode ser confusa;
* Excesso de informação;
* Dificuldade para novos usuários;
* Conteúdo nem sempre possui qualidade consistente.

**O que aproveitar**

* Sistema de comentários;
* Votação/curtidas;
* Organização por categorias/comunidades;
* Destaque para conteúdos mais relevantes.

---

### Letterboxd

**Pontos positivos**

* Interface focada no conteúdo;
* Sistema de avaliação simples;
* Listas personalizadas;
* Histórico do usuário;
* Perfis com atividades;
* Facilidade para descobrir novos conteúdos.

**Pontos negativos**

* Algumas funções são pagas;
* Algumas telas podem apresentar bastante informação;
* Experiência mais limitada para quem não deseja utilizar recursos sociais.

**O que aproveitar**

* Sistema de notas;
* Reviews;
* Listas personalizadas;
* Histórico de avaliações;
* Perfil mostrando os jogos avaliados;
* Descoberta de jogos baseada nas avaliações.
