## Feedbacks

Os usuários e entrevistados gostaram bastante do protótipo, destacando principalmente a avaliação dos jogos, em que várias opções são opcionais. Isso torna o processo mais rápido e simples para quem deseja fazer uma avaliação breve, mas também permite adicionar mais detalhes caso o usuário queira.
